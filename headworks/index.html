Penstock v0.5.3 · Cistern v0.3.1

Headworks has its own release now, with both parts pinned together by digest. It isn't public yet, so talk to us if you'd like access. Until then, each part ships on its own release, and Cistern's demo starts both on your machine with one command.

A self-hosted AI agent that reads only what you share.

A self-hosted AI agent: Penstock and Cistern running together on your machine. It runs on the model you choose (a local Ollama, Copilot, Anthropic or OpenAI), remembers what you taught it, reads only the data you shared, and gets a receipt for every read.

Headworks is a self-hosted AI agent you can hand real work to. It runs on your own machine, with a model you pick, in the folder you give it to work in. When it needs something from your Cistern pod, it has to ask. You decide, and you can change your mind: take the access back and its very next request is refused. Every yes and every no is written down where you can read it. That's Headworks: two open-source parts, running together. Penstock is the assistant, and it keeps a record of its work. Cistern is where your data lives, and the gate in front of it.

What happens when it asks
Penstock asks Cistern for a file through its pod tool, using a credential of its own by default, not yours. Cistern checks your grant, then either hands the file over or says no. Either way, it writes a receipt. Revoke the grant, and the next ask gets a no.

What it remembers

Its memory is plain files you own and can read, change or delete. It goes into the model's prompt; Penstock doesn't train a model on it.

How the record grows, in Penstock v0.5.3
Episodes What
happened

A script you run drafts one from a finished task's PR and commits: what was asked, decided, refused, learned, and what is still open. You edit the draft.

→↓
Facts What you
now believe

A script you run proposes them from the episodes' learned lines, and you choose which to keep. One per file, with where it came from. A changed mind supersedes the old fact; it is never quietly overwritten.

→↓
Patterns How it was
built before

For a task worth repeating, a script you run scaffolds one from its changes: the decisions, a skeleton and a check. You review it like any other change. With memory on, a matching pattern joins the prompt, space permitting.

Each fact, episode and pattern the agent loads is written to its audit log when Penstock stores to a database, so you can see what it remembered and when. Memory stays off until you turn it on. The parts02

What each part does today

Each line is something a released part does today. We checked every one against that part's release tag.

Works on your data
Penstock runs on your own hardware, with the model you choose, a local one included. When it needs your data, it goes through its pod tool to a Cistern pod. v0.5.3
Remembers
Penstock keeps a record of what you asked, what was decided, what was refused and what it learned, as plain files you own. Turn memory on (it's off by default in the web and IDE modes) and it reads that record before it answers. Split the record into projects, and each project sees its own section, never another's. More on the record it keeps. in Penstock v0.5.3
Sees only what you share
Cistern checks your grant on every single request. It never caches a decision, so when you take access back, the very next request is refused. v0.3.1
Keeps a receipt
Cistern writes down every allow and every deny, and you can look them up file by file. Penstock logs every model call and tool call to its audit log when it stores to a database.
Learns how you work
A persona that answers from your record, points to the card behind each decision, and asks you when the record has nothing to say (penstock#93). planned
Run them together03

Try them together

Two ways, each straight from the parts' own docs, with every step linked. Both run on your machine and listen only on 127.0.0.1.

One command
Cistern's demo brings up a pod and Penstock with a single docker compose command, the agent on its own credential. Then it walks you through five beats: put a file in, watch the agent get refused, grant access, watch it read, revoke, and watch it get refused again. The demo pins Penstock 0.2.0, an older release.
