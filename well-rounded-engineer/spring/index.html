Spring Boot

Spring Boot 3.x on Java 17+, with what 3.2–3.5 added and what changed in 4.0 and 4.1. The examples are 3.x; 4.0 renamed or removed some properties, so check its migration guide. Servlet (MVC) and reactive (WebFlux) shown side by side.

Version map

VerYearWhat changed
2.72022Last 2.x line. Java 8+, javax.* packages
3.02022Java 17 baseline, Jakarta EE 9+ (javax.* → jakarta.*), Micrometer Observation, GraalVM native images, ProblemDetail
3.12023Testcontainers @ServiceConnection, Docker Compose support
3.22023Virtual threads (spring.threads.virtual.enabled), RestClient, JdbcClient
3.32024Class Data Sharing support, SBOM actuator endpoint
3.42024Structured logging (ECS, Logstash, GELF), @MockitoBean replaces @MockBean, graceful shutdown by default
3.52025The last 3.x feature release; upgrade here before moving to 4.x
4.02025Spring Framework 7, Jakarta EE 11, Jackson 3, smaller modular starters, API versioning, JSpecify null-safety; deprecated 3.x APIs removed
4.12026Spring gRPC support, SSRF protection for HTTP clients (InetAddressFilter), OpenTelemetry improvements

Moving to 4.0: upgrade to the latest 3.5 first, clear every deprecation warning, then follow the official migration guide.

Data access

// JdbcClient (3.2): plain SQL, records out
@Repository
class OrderDao {
  private final JdbcClient jdbc;
  OrderDao(JdbcClient jdbc) { this.jdbc = jdbc; }

  Optional<OrderDto> find(String orderRef) {
    return jdbc.sql("SELECT order_ref, order_date FROM orders WHERE order_ref = :order_ref")
               .param("order_ref", orderRef)
               .query(OrderDto.class)
               .optional();
  }
  int upsert(OrderDto o) {
    return jdbc.sql("""
        INSERT INTO orders (order_ref, order_date) VALUES (:order_ref, :d)
        ON CONFLICT (order_ref) DO UPDATE SET order_date = EXCLUDED.order_date""")
      .param("order_ref", o.orderRef()).param("d", o.orderDate()).update();
  }
}

// Spring Data JPA
interface OrderRepo extends JpaRepository<Order, Long> {

}

HTTP clients

// RestClient (3.2): synchronous, fluent
@Bean RestClient supplier(RestClient.Builder b) {
  return b.baseUrl("https://api.example.org").build();
}

Listing l = supplier.get()
    .uri("/objects?prefix={p}", prefix)
    .retrieve()
    .onStatus(HttpStatusCode::is4xxClientError, (req, res) -> {
      throw new IllegalStateException("listing failed: " +
          new String(res.getBody().readAllBytes()));   // keep the error body
    })
    .body(Listing.class);

// Declarative interface client
interface SupplierApi {
  @GetExchange("/objects") Listing list(@RequestParam String prefix);
}
@Bean SupplierApi api(RestClient supplier) {
  return HttpServiceProxyFactory.builderFor(RestClientAdapter.create(supplier))
      .build().createClient(SupplierApi.class);
}

Errors as ProblemDetail

@RestControllerAdvice
class ApiErrors {
  @ExceptionHandler(NotFoundException.class)
  ProblemDetail notFound(NotFoundException e) {
    ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, e.getMessage());
    pd.setTitle("Order not found");
    pd.setProperty("orderRef", e.orderRef());
    return pd;
  }
}
// application.yml: spring.mvc.problemdetails.enabled: true
//                  (spring.webflux.problemdetails.enabled for WebFlux)
// Response: application/problem+json {type,title,status,detail,instance,orderRef}

Batch job / Cloud Run job

// No web server; run once and exit with a code
@SpringBootApplication
class LoaderApp {
  public static void main(String[] args) {
    System.exit(SpringApplication.exit(SpringApplication.run(LoaderApp.class, args)));
  }
  @Bean ApplicationRunner run(Loader loader) {
    return args -> loader.load(args.getOptionValues("year"));   // --year=2024
  }
  @Bean ExitCodeGenerator exitCode(Loader loader) {
    return () -> loader.failed() ? 1 : 0;
  }
}

@Service

Testing

@WebMvcTest(OrderController.class)          // web slice only
class OrderControllerTest {
  @Autowired MockMvc mvc;
  @MockitoBean OrderService svc;            // 3.4+ (was @MockBean)

  @Test void returns404() throws Exception {
    when(svc.get(any())).thenThrow(new NotFoundException("x"));
    mvc.perform(get("/api/orders/{id}", UUID.randomUUID()))
       .andExpect(status().isNotFound())
       .andExpect(jsonPath("$.title").value("Order not found"));
  }
}

Actuator & observability

management:
  endpoints.web.exposure.include: health,info,metrics,prometheus
  endpoint.health.probes.enabled: true    # /actuator/health/liveness, /readiness
  tracing.sampling.probability: 0.1

// custom metric
@Component
class LoadMetrics {
  private final Counter loaded;
  LoadMetrics(MeterRegistry r) { loaded = r.counter("orders.rows.loaded"); }
  void add(long n) { loaded.increment(n); }
}

// custom health
@Component
class SupplierHealth implements HealthIndicator {
  public Health health() {
    return reachable() ? Health.up().build()
                       : Health.down().withDetail("supplier", "unreachable").build();
  }
}

Replace the x with the current patch version. Let the Boot BOM pick library versions; override only with a reason.

Levels: what to expect

1 Foundation

  • Build a REST endpoint with validation and a test
  • Configure an app with application.yml and profiles
  • Use Spring Data or JdbcClient for simple queries

2 Practitioner

  • Handle errors with ProblemDetail; write slice and integration tests
  • Use transactions correctly; understand proxies
  • Add Actuator, metrics and structured logging

3 Senior

  • Choose servlet vs reactive and design for throughput
  • Secure APIs with Spring Security and OAuth 2.0
  • Tune startup, memory and connection pools for the cloud

4 Expert

  • Lead major upgrades (3.x to 4.x) across services
  • Build internal starters and platform libraries
  • Set architecture and module boundaries (Spring Modulith)

Each level includes the ones before it. See Start here for what the levels mean.
