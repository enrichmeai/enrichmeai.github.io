CLI & dev mode

quarkus create app org.acme:corpus-api \
  --extension='rest-jackson,hibernate-orm-panache,jdbc-postgresql,hibernate-validator'
quarkus ext list --installable
quarkus ext add smallrye-health micrometer-registry-prometheus

quarkus dev                  # live reload; press r to run tests, d for Dev UI
./mvnw quarkus:dev           # same with Maven
./gradlew quarkusDev         # same with Gradle

./mvnw package               # target/quarkus-app/quarkus-run.jar
java -jar target/quarkus-app/quarkus-run.jar
./mvnw package -Dnative      # native binary (GraalVM / Mandrel)
./mvnw package -Dnative -Dquarkus.native.container-build=true   # no local GraalVM

Dev UI: http://localhost:8080/q/dev-ui. Ship target/quarkus-app/ as a directory; the -run.jar alone is not runnable.

REST endpoint

@Path("/api/judgments")
@Produces(MediaType.APPLICATION_JSON)
public class JudgmentResource {
  private final JudgmentService svc;
  JudgmentResource(JudgmentService svc) { this.svc = svc; }   // constructor injection

  @GET @Path("/{id}")
  public JudgmentDto get(@RestPath UUID id) { return svc.get(id); }

  @GET
  public List<JudgmentDto> list(@RestQuery @DefaultValue("0") int page) { ... }

  @POST @Path("/search")
  public List<JudgmentDto> search(@Valid SearchRequest req) { return svc.search(req); }

  @GET @Path("/{id}/raw")
  public RestResponse<String> raw(@RestPath UUID id) {
    return svc.raw(id).map(RestResponse::ok)
              .orElse(RestResponse.notFound());
  }
}

Data with Panache

// Active record
@Entity
public class Judgment extends PanacheEntity {     // gives Long id
  public String cnr;
  public LocalDate decisionDate;

  public static Optional<Judgment> byCnr(String cnr) {
    return find("cnr", cnr).firstResultOptional();
  }
}

// Repository style
@ApplicationScoped
public class JudgmentRepo implements PanacheRepository<Judgment> {
  public List<Judgment> recent(String court) {
    return list("courtCode = ?1 and decisionDate > ?2 order by decisionDate desc",
                court, LocalDate.now().minusDays(30));
  }
}

@Transactional
public void save(Judgment j) { j.persist(); }

Judgment.find("courtCode", "2_5").page(Page.of(0, 50)).list();
Judgment.count("decisionDate is null");

REST client

@RegisterRestClient(configKey = "mirror")
@Path("/objects")
public interface MirrorClient {
  @GET Listing list(@RestQuery String prefix);
  @GET @Path("/{key}") Uni<byte[]> fetch(@RestPath String key);   // reactive
}

# application.properties
quarkus.rest-client.mirror.url=https://api.example.org
quarkus.rest-client.mirror.read-timeout=10000

@Inject @RestClient MirrorClient mirror;

// fault tolerance (quarkus-smallrye-fault-tolerance)
@Retry(maxRetries = 3, delay = 200)
@Timeout(10_000)
@CircuitBreaker(requestVolumeThreshold = 10)
public Listing safeList(String p) { return mirror.list(p); }

Threading: blocking, reactive, virtual

// Blocking signature → worker thread (default for non-Uni returns)
@GET public List<JudgmentDto> list() { ... }

// Reactive signature → event loop: never block inside it
@GET public Uni<JudgmentDto> get(@RestPath UUID id) {
  return client.fetch(id)
      .onItem().transform(this::toDto)
      .onFailure().retry().atMost(3)
      .ifNoItem().after(Duration.ofSeconds(5)).fail();
}

Multi.createFrom().iterable(uris)
     .onItem().transformToUniAndMerge(this::fetch);   // concurrent

// Virtual threads (Java 21+)
@GET @RunOnVirtualThread

Errors, health, metrics

public class ErrorMappers {
  @ServerExceptionMapper
  public RestResponse<Map<String, String>> notFound(NotFoundException e) {
    return RestResponse.status(Response.Status.NOT_FOUND,
        Map.of("error", "not_found", "cnr", e.cnr()));
  }
}

@Readiness @ApplicationScoped
public class MirrorCheck implements HealthCheck {
  public HealthCheckResponse call() {
    return HealthCheckResponse.named("mirror").status(reachable()).build();
  }
}

Jobs & scheduling

// Command mode: run once, exit with a code (Cloud Run job, K8s Job)
@QuarkusMain
public class LoaderMain implements QuarkusApplication {
  @Inject Loader loader;
  @Override public int run(String... args) {
    return loader.load(args) ? 0 : 1;
  }
}

Testing

@QuarkusTest
class JudgmentResourceTest {
  @InjectMock JudgmentService svc;        // quarkus-junit5-mockito

  @Test void returns404() {
    when(svc.get(any())).thenThrow(new NotFoundException("x"));
    given().when().get("/api/judgments/{id}", UUID.randomUUID())
           .then().statusCode(404)
           .body("error", is("not_found"));
  }
}

@QuarkusIntegrationTest                    // runs against the built jar or native binary
class JudgmentResourceIT extends JudgmentResourceTest {}

@TestProfile(NoSchedulerProfile.class)     // per-test config overrides
public class NoSchedulerProfile implements QuarkusTestProfile {
  public Map<String, String> getConfigOverrides() {
    return Map.of("quarkus.scheduler.enabled", "false");
  }
}

Native images start in tens of milliseconds and use less memory, which suits Cloud Run and scale-to-zero. Libraries that rely on reflection need native config; test the native build in CI.

Levels: what to expect

1 Foundation

  • Create a project and run dev mode
  • Write a REST endpoint and a @QuarkusTest
  • Configure with application.properties and profiles

2 Practitioner

  • Use Panache, REST clients and fault tolerance
  • Choose blocking, reactive or virtual-thread endpoints
  • Package as a container; use Dev Services

3 Senior

  • Build and run native images; fix reflection issues
  • Design for Kubernetes and serverless startup
  • Migrate services from Spring with clear trade-offs

4 Expert

  • Write Quarkus extensions
  • Set framework strategy across Spring and Quarkus estates
  • Understand build-time processing and ArC internals

Each level includes the ones before it. See Start here for what the levels mean.
