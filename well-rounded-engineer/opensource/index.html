Our open source

What EnrichMeAI builds in the open, kept apart from the learning pages. The guide stays neutral; these are the real projects, each with its own page and source.

Cistern

A self-hostable data server built on the Solid specifications. Apps and AI assistants ask permission instead of taking copies: the owner writes the rule, Cistern enforces it on every request, and every allow and deny gets a receipt. Java, Apache 2.0.

The Cistern page · Source and issues

Penstock

A self-hosted agent harness. With database storage, every model call and tool call is written to an audit log the owner reads back, and its pod tool reads from a Cistern pod only what was granted. Java, Spring Boot.

The Penstock page · Source and issues

Culvert

A cloud-agnostic data-pipeline framework: pipelines are defined once against a language-neutral contract set and run on any cloud by swapping adapters. Java and Python, Apache 2.0. The guide's Culvert page teaches the ideas.

The Culvert page · Source and issues

enrich-test-api

Java integration tests for cloud code, on local emulators: a test asks for a bucket or a queue and gets one, backed by a container the library started, so no cloud account is needed. An alpha, and its page says so. Java 17, Apache 2.0.

The enrich-test-api page · Source and issues

Learning from them

The learning pages use neutral examples on purpose, so they teach the idea rather than a product. When you want to see an idea in a real codebase, these projects are where to look: Agent Harness and Penstock, Solid and Cistern, Data Engineering and Culvert, Testing and enrich-test-api. Headworks shows Penstock and Cistern running together. Questions about a project go to that project's issues.

Checked against: each project's own page on this site and its repository at its latest release tag: Cistern; Penstock; Culvert; enrich-test-api. Versions are kept in step by the site's release checker.
