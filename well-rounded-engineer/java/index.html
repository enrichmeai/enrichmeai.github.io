// Pattern matching switch + record patterns: exhaustive over a sealed type
String describe(Outcome o) {
  return switch (o) {
    case Ok(long rows) when rows == 0 -> "empty";
    case Ok(long rows)                -> rows + " rows";
    case Failed(String why)           -> "failed: " + why;
  };   // no default needed: compiler checks exhaustiveness
}

// Virtual threads: one cheap thread per blocking task

  for (var f : fs) handle(f.get());
}   // ExecutorService is AutoCloseable since 19: close() waits

Virtual threads suit blocking I/O (HTTP, JDBC, GCS). Do not pool them. CPU-bound work still wants a fixed pool.

BigQuery bq = BigQueryOptions.getDefaultInstance().getService();

QueryJobConfiguration q = QueryJobConfiguration.newBuilder("""
    SELECT court, COUNT(*) n FROM `proj.fdp.judgment`
    WHERE decision_date >= @from GROUP BY court""")
  .addNamedParameter("from", QueryParameterValue.date("2024-01-01"))

  long n = row.get("n").getLongValue();
}

// Load parquet from GCS
LoadJobConfiguration load = LoadJobConfiguration
  .newBuilder(TableId.of("odp", "hc_judgment"), "gs://bkt/path/*.parquet",
              FormatOptions.parquet())
  .setWriteDisposition(JobInfo.WriteDisposition.WRITE_APPEND)
  .build();
Job job = bq.create(JobInfo.of(load)).waitFor();
if (job.getStatus().getError() != null) throw new IllegalStateException(

// Dry run: bytes before you pay

    q.toBuilder().setDryRun(true).setUseQueryCache(false).build()))
  .getStatistics();

        .fromQuery("SELECT cnr, court FROM `proj.odp.hc_judgment`")

Build & run flags

// Gradle (Kotlin DSL): pin the JDK, not whatever is on PATH
java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }
tasks.withType<JavaCompile> { options.release = 21 }

// Preview features (compile AND run)
javac --release 25 --enable-preview Foo.java
java --enable-preview Foo

// Containers: size heap from cgroup limits
java -XX:MaxRAMPercentage=75 -XX:+UseZGC -jar app.jar

// AOT cache (24/25): faster startup
java -XX:AOTCacheOutput=app.aot -jar app.jar   # training run (25)
java -XX:AOTCache=app.aot -jar app.jar

"Unsupported class file major version" means the build JDK is newer than the tool (often Gradle) supports. Set JAVA_HOME to the version the build expects.

Levels: what to expect

1 Foundation

  • Write classes, records, collections and streams
  • Use Optional and java.time correctly
  • Run and write JUnit tests

2 Practitioner

  • Use modern features (records, sealed types, pattern switch, virtual threads)
  • Handle concurrency safely with executors and CompletableFuture
  • Build with Gradle or Maven and manage dependencies

3 Senior

  • Tune the JVM for containers (memory, GC, startup)
  • Design APIs and module boundaries
  • Profile and fix performance problems

4 Expert

  • Lead platform upgrades across LTS releases
  • Understand JVM internals (JIT, GC, class loading)
  • Set the organisation's Java standards and libraries

Each level includes the ones before it. See Start here for what the levels mean.
