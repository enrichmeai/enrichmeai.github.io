How computers are built

From the first microprocessor to the laptop on your desk: instruction sets, how software talks to devices, sound and media, and how graphics chips built for games became the engines of AI. Start with Electronics & Chips.

RISC and CISC

  • An instruction set is the list of operations a processor understands: the contract between hardware and software.
  • CISC (complex instruction set computer): instructions can do several things at once, such as load from memory, calculate and store, with many addressing modes. x86, in most PCs and servers, is the best-known CISC family.
  • RISC (reduced instruction set computer): fewer, simpler instructions that each do one thing, so the chip can run them quickly and efficiently. The ideas came from projects such as IBM's 801 in the late 1970s and work at Berkeley and Stanford. ARM (originally Acorn RISC Machine, 1985) and RISC-V are RISC.
  • Today the line is blurred: modern x86 chips translate complex instructions into simpler internal steps, and RISC chips have grown richer. The practical difference now is mostly power efficiency, licensing and the software ecosystem.

Programming devices

  • Microcontrollers are small computers on one chip: processor, memory and inputs and outputs. They run washing machines, cars, sensors and robots.
  • Firmware is the software built into a device, usually stored in flash memory. You "flash" new firmware to update it.
  • Device drivers let the operating system control hardware: a driver turns "play this sound" or "print this page" into the device's own commands.
  • Try it: program a microcontroller board to blink a light, read a sensor and drive a motor. It teaches timing, memory limits and the hardware underneath every abstraction. See Robotics.

How a modern laptop is built

  • System on a chip (SoC): CPU cores, a graphics processor, AI and media engines and security functions on one chip, often with memory packaged right beside it and shared between them.
  • Storage: a solid-state drive on the PCI Express bus, spoken to with the NVMe protocol: no moving parts, far faster than a spinning disk.
  • Power and heat: the battery and cooling decide how hard the chip can work and for how long; thin laptops trade peak speed for quiet and battery life.
  • Firmware first: when you press the power button, firmware checks the hardware and starts the operating system.

Media and sound cards

  • MIDI (standardised 1983) lets instruments and computers exchange notes and controls rather than recorded sound.
  • Sound cards gave early PCs real audio: AdLib (founded 1987) and then Creative's Sound Blaster (1989), which became the de facto standard for PC audio until Windows 95 and audio built into the motherboard took over.
  • Integrated audio: today sound is part of the motherboard or chip, following Intel's AC'97 and High Definition Audio (2004) specifications.
  • The pattern repeats: a separate card proves a need, then the function moves onto the main chip. Graphics went the same way in laptops.

From gaming graphics to AI

  1. 1995 to 1999, 3D for games: 3dfx's Voodoo Graphics chip (to manufacturing in November 1995) brought fast 3D to PC gaming. In 1999 Nvidia marketed the GeForce 256 as "the world's first GPU", popularising the term.
  2. Why GPUs are different: drawing a frame means doing the same small calculation on millions of pixels at once, so GPUs have thousands of simple cores built for parallel arithmetic, where a CPU has a few complex ones.
  3. 2007, CUDA: Nvidia's CUDA let ordinary programs use the GPU for general-purpose computing, opening it to science and engineering.
  4. 2012, AlexNet: a neural network for image recognition, trained on two Nvidia GTX 580 gaming GPUs, entered the ImageNet challenge and showed that GPUs made deep learning practical.
  5. 2015 to 2017, chips for AI: Google introduced its Tensor Processing Unit (TPU), a chip designed only for neural networks, and Nvidia's Volta GPUs (first product announced May 2017) added Tensor Cores for deep learning.

Neural networks are mostly large matrix multiplications, exactly the parallel arithmetic that games had already paid to make fast and cheap. See LLMs and Mathematics.

Levels: what to expect

1 Foundation

  • Explain what an instruction set is, and RISC versus CISC
  • Explain firmware and device drivers
  • Explain why GPUs suit graphics and AI

2 Practitioner

  • Program a microcontroller to read a sensor and drive an output
  • Read a laptop or server spec sheet and know what each part does
  • Run a workload on a GPU and compare it with the CPU

3 Senior

  • Choose hardware for a workload: cores, memory, storage, accelerators
  • Profile where time goes between CPU, memory, disk and GPU
  • Plan for ARM and x86 in the same estate

4 Expert

  • Set hardware strategy for a platform or data centre
  • Co-design software with accelerators
  • Lead a move between processor architectures

Each level includes the ones before it. See Start here for what the levels mean.
