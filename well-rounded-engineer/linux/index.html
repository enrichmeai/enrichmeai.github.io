Linux

The commands you need on a server, in a container, or in a CI runner. Networking commands live on the Networking tab.

Where things live

PathHolds
/etcsystem configuration
/var/loglogs (when not in the journal)
/var/libservice data (docker, postgres)
/tmptemporary files, often cleared on reboot (depends on the distribution)
/home, /rootuser homes
/usr/bin, /usr/local/binprograms; local installs go in /usr/local
/optself-contained third-party software
/proc, /syslive kernel and process information
/devdevices

Processes & signals

ps aux | grep java
ps -eo pid,ppid,%cpu,%mem,etime,cmd --sort=-%mem | head
pgrep -af gunicorn
top / htop                               # P cpu, M memory, k kill
kill PID                                 # SIGTERM: ask nicely
kill -9 PID                              # SIGKILL: cannot be caught, no cleanup
pkill -f 'python -m loader'
lsof -i :8080                            # who holds the port
lsof -p PID | wc -l                      # open files
nohup ./job.sh > job.log 2>&1 &          # survive logout
jobs; fg %1; bg; disown
timeout 300 ./slow.sh                    # kill after 5 min
nice -n 10 ./batch.sh                    # lower priority

Exit codes: 0 success; 1 general error; 126 not executable; 127 command not found; 128+N killed by signal N (137 = 128+9 SIGKILL, 143 = 128+15 SIGTERM).

Disk, memory, system

df -h                     # free space per filesystem
df -i                     # inodes: "no space" with free GB means inodes
du -xh / --max-depth=1 2>/dev/null | sort -h
free -h                   # "available" is what matters, not "free"
uptime                    # load average: compare with CPU count
nproc; lscpu; lsblk
vmstat 1 5                # run queue, swap, IO wait
iostat -x 1               # disk busy (sysstat)
dmesg -T | tail           # kernel: OOM killer, disk errors
uname -a; cat /etc/os-release
ulimit -n                 # max open files for this shell

Permissions & users

ls -l f        # -rwxr-x--- 1 app app ...  owner / group / others
chmod 640 f    # rw- r-- ---   (r=4 w=2 x=1)
chmod u+x run.sh
chmod -R g+rX dir/            # X: execute only on dirs
chown app:app f; chown -R 1001:1001 /data
id; whoami; groups
sudo -u app ./run.sh
sudo useradd -r -s /usr/sbin/nologin app     # service account, no login
umask                          # default permission mask

Private keys must not be readable by group or others (600 or 400), or SSH refuses them. A directory needs x to be entered and r to be listed.

systemd & logs

systemctl status nginx
sudo systemctl restart nginx
sudo systemctl enable --now myapp     # start now and on boot
systemctl list-units --failed
journalctl -u myapp -f                # follow one service
journalctl -u myapp --since "1 hour ago" -p err
journalctl -b -1                      # previous boot

[Install]

# then: sudo systemctl daemon-reload

Safe bash scripts

#!/usr/bin/env bash
set -euo pipefail          # stop on error, unset var, or failed pipe stage
IFS=$'\n\t'

usage() { echo "usage: $0 <env> <date>" >&2; exit 2; }
[[ $# -eq 2 ]] || usage
env="$1"; date="$2"
[[ "$env" =~ ^(dev|prod)$ ]] || { echo "bad env: $env" >&2; exit 2; }

tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT  # always clean up

log() { printf '%s %s\n' "$(date -u +%FT%TZ)" "$*" >&2; }

for f in data/*.csv; do
  [[ -e "$f" ]] || continue          # glob matched nothing
  log "loading $f"
done

# capture an exit code without dying under set -e
if ! out="$(some_command 2>&1)"; then
  log "failed: $out"; exit 1
fi
# shellcheck script.sh   ← run it

Quote every variable ("$f"). Unquoted values split on spaces and expand globs.

Pipes, redirects, environment

cmd > out.txt          # stdout to file (overwrite)
cmd >> out.txt         # append
cmd 2> err.txt         # stderr
cmd > all.txt 2>&1     # both (order matters)

cmd <<'EOF'            # heredoc; quotes stop $ expansion

EOF

Levels: what to expect

1 Foundation

  • Navigate, read and search files and logs
  • Run, stop and inspect processes
  • Understand permissions well enough to fix 'permission denied'

2 Practitioner

  • Write safe bash scripts with set -euo pipefail, traps and quoting
  • Diagnose disk, memory and CPU problems with df, free, top, dmesg
  • Manage services with systemd and read journalctl

3 Senior

  • Tune a host or container for a workload (file limits, memory, I/O)
  • Debug with strace, lsof and tcpdump
  • Decide when a script should become a real program

4 Expert

  • Understand kernel mechanisms behind containers (namespaces, cgroups)
  • Set the team's base images and hardening standards
  • Lead performance investigations end to end

Each level includes the ones before it. See Start here for what the levels mean.
