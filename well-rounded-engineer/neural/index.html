Neural networks

Most modern models for image recognition, speech and language are built from neural networks: many simple units, each doing a little arithmetic, connected in layers and tuned on data. This page explains one unit, how units form layers, how a network learns, the main kinds of network, and how the field got here. How large language models work in particular is on LLMs; why GPUs suit this work is on How Computers Are Built.

The short answer

A neural network is layers of simple units. Each unit multiplies its inputs by weights, adds them up and applies a small non-linear function. Training shows the network many examples, measures how wrong its answers are, and nudges every weight a little in the direction that makes the error smaller, again and again.

One neuron

An artificial neuron takes several inputs, multiplies each by a weight, adds them up with a bias, and passes the total through an activation function. The weights are loosely analogous to the strengths of synapses between biological neurons. Warren McCulloch and Walter Pitts described a simple, non-learning model of this kind in 1943.

import math

x = [0.5, 0.8, 0.2]      # inputs
w = [0.4, 0.6, -0.9]     # weights
b = 0.1                  # bias

z = sum(xi * wi for xi, wi in zip(x, w)) + b   # weighted sum
y = 1 / (1 + math.exp(-z))                     # sigmoid activation
print(f"z = {z:.2f}, y = {y:.3f}")
# z = 0.60, y = 0.646

Run as shown with Python 3; the last line is its real output.

Layers

  • Input layer: the numbers you feed in, such as pixel values or the features of a transaction.
  • Hidden layers: neurons whose outputs feed the next layer. This shape, fully connected layer to layer, is called a multilayer perceptron.
  • Output layer: the answer, such as a score per class.
  • Non-linear activations matter: with a non-linear activation function, even a few neurons can solve non-trivial problems; the universal approximation theorems show that suitable networks can, in principle, approximate any continuous function.

How a network learns

  1. Predict: run training examples forward through the network.
  2. Measure the error with a loss function, a single number that training tries to make as small as possible.
  3. Find which way to move each weight: backpropagation applies the chain rule of calculus efficiently to get the gradient of the loss with respect to every weight. Rumelhart, Hinton and Williams’ 1986 paper in Nature, “Learning representations by back-propagating errors”, describes the method.
  4. Take a small step: gradient descent moves each weight a little in the direction opposite to the gradient, the direction of steepest descent. The size of the step is the learning rate.
  5. Repeat over many batches. Stochastic gradient descent estimates the gradient from a randomly chosen subset of the data each time, instead of the whole data set.

The risk is overfitting: a model that matches its training data too closely and then fails on new data. That is why models are checked on data held back from training.

Activation functions

FunctionWhat it does
SigmoidSquashes any number into the range 0 to 1 (used in the code above)
ReLUPasses positive values, turns negatives into 0; used in the 2012 AlexNet image model
GELUA smooth version of ReLU, used in the 2018 BERT language model
SoftmaxTurns a list of scores into a probability distribution over the possible outcomes, often on the output layer

Kinds of network

  • Feedforward (multilayer perceptron): data flows one way, layer to layer, as in the diagram.
  • Convolutional (CNN): learns small filters, or kernels, that slide across the input; widely used for images.
  • Recurrent (RNN): feeds its output back in, for sequences. Plain RNNs suffer from the vanishing gradient problem, which limits long-range memory; the LSTM, by Hochreiter and Schmidhuber (1997), was designed to ease it.
  • Transformer: introduced in the 2017 paper “Attention Is All You Need” by eight researchers at Google, built on the attention mechanism. Many modern large language models are built on it (see LLMs).

A short history

YearWhat happened
1943McCulloch and Pitts describe a non-learning computational model of neurons.
1958Frank Rosenblatt describes the perceptron, one of the first implemented neural networks.
1969Minsky and Papert’s book Perceptrons sets out limits of simple perceptrons, such as computing XOR (they already knew multi-layer perceptrons could). It is claimed that its pessimism helped turn research towards symbolic systems.
1986Rumelhart, Hinton and Williams publish their backpropagation paper in Nature.
2012AlexNet, a convolutional network trained on GPUs, wins the ImageNet image-recognition challenge with a top-5 error rate of 15.3%.
2017The transformer is introduced in “Attention Is All You Need”.

Choose by requirement

If this is true for youIt leans towards (analysis)
Tabular data with a modest number of rows and a need to explain decisionsSimpler models first (linear models, decision trees); a neural network only if they fall short
Images or other grid-shaped dataA convolutional network, or a pre-trained model to fine-tune
Text, code or other sequencesA transformer, usually a pre-trained one used through an API or fine-tuned (see LLMs)
Little labelled dataA pre-trained model adapted to your task, rather than training from scratch
Your team already runs one ML frameworkStay with it unless a requirement forces a change: switching has a cost

These leanings are analysis, not sourced facts; the other way is to try a neural network first and measure it against a simpler model.

Our view, and the other view

Our view: every engineer who works with AI benefits from understanding one neuron, a loss and a gradient step well enough to explain them. It makes the behaviour of large models, and the limits of what they learned, less mysterious.

The other view: most engineers use models through an API and never train one. For them, time may be better spent on evaluation, prompting, cost and safety than on the mathematics of training.

Levels: what to expect

1 Foundation

  • Explain a neuron: weights, bias, activation
  • Draw a network's input, hidden and output layers
  • Say what non-linear activations make possible

2 Practitioner

  • Compute a neuron's output by hand and in code
  • Explain loss, gradient descent and the learning rate
  • Recognise overfitting and hold back data to check for it

3 Senior

  • Explain backpropagation as the chain rule
  • Choose between feedforward, convolutional, recurrent and transformer networks
  • Decide between training, fine-tuning and using a pre-trained model

4 Expert

  • Set an organisation's approach to building versus buying models
  • Judge claims about model capability against how training works
  • Plan evaluation for models in production

Each level includes the ones before it. See Start here for what the levels mean.
