Guide / User interfaces / UI History

A short history of user interfaces

From text screens to declarative UIs: each step made it easier to describe what people should see, and moved more work from the programmer to the framework.

Timeline

WhenWhatWhy it mattered
Before the 1980sText terminals and command linesType a command, read the answer. Still used for many engineering tasks. See Linux.
1973Xerox AltoAn early computer with a graphical interface and a mouse.
1984Apple MacintoshBrought the graphical interface to a mass-market personal computer.
1985Windows 1.0 (November 1985)Microsoft's graphical environment on top of DOS.
1993Mosaic web browserMade the web graphical and popular; pages were documents, not applications.
1995 onwardsJava appletsPrograms inside the browser. Browsers dropped the plug-in support they needed in the 2010s.
1996 to 2020FlashRich animation and video in the browser through a plug-in; its player was retired at the end of 2020.
1999, named 2005XMLHttpRequest, then "Ajax"Pages could fetch data without reloading. The term Ajax was coined in February 2005.
2006jQuerySmoothed over browser differences and made page scripting approachable.
2007 and 2008The first iPhone, then AndroidTouch-first phones, app stores, and native mobile development.
2010 to 2014AngularJS (2010), React (2013), Vue (2014)Single-page applications: the browser builds the UI from data and calls APIs.
2015React Native; "progressive web app" coinedWeb skills reach native apps; web apps learn to install and work offline.
2018 to 2021Flutter 1.0 (2018), SwiftUI (2019), Jetpack Compose (2021)Declarative UI comes to mobile: describe the screen, let the framework update it.

What stays the same

Every generation repeats the same lessons: keep the interface responsive while work happens in the background, separate what is shown from the data behind it, make it usable by everyone (see Web Fundamentals for accessibility), and test it the way people use it. The tools change; those do not.

Checked against (Wikipedia): Xerox Alto; Macintosh 128K; Windows 1.0; Mosaic; Java applet; Adobe Flash; Ajax; jQuery; iPhone; Android; AngularJS; React; Vue.js; React Native; Progressive web app; Flutter; SwiftUI; Jetpack Compose.
